## 🚀 Quick Reference

* **Start GUI:** Run `run_gui.bat` or `python main.py --gui`
* **Start CLI:** Run `run_cli.bat` or `python main.py`
* **Register Faces:** `python add_faces.py` or drag images into `known_faces/`
* **Configuration:** Edit settings in `config/config.yaml`
